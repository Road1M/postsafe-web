Ein Freund nutzt PostSafe und möchte, dass du es auch ausprobierst.

Sein Code

So geht es

  1. Lade PostSafe aus dem App Store.
  2. Melde dich in der App an.
  3. Öffne Du, dann unter Mitmachen die Zeile Einladungscode eingeben, und gib den Code ein. Das geht in den ersten 14 Tagen nach der Anmeldung.

Sobald du deinen ersten Brief ablegst, bekommt dein Freund dafür Punkte in der App. Er erfährt dabei nicht, wer du bist, nur dass jemand mit seinem Code dabei ist.
